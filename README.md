# Serve the Bass

Drop in an mp3 and hear it from inside a car with the sub hitting.

Everything runs in the browser with the Web Audio API. Files are never uploaded anywhere.

- Ride presets: Sedan, Hatchback, Trunk, Next lane
- Bass, Tune, Knock, Muffle, Cabin, Rattle and Volume controls
- Soft clip button that trims 808 peaks so vocals come through

Made by Capitalogy.

## Run it

Open `index.html` in a browser. There is no build step and nothing to install.
